# 여행 플래너 — 설치 및 설정 가이드

이 앱은 **설정을 하나도 하지 않아도 바로 사용할 수 있습니다.**
아래 단계는 기능을 하나씩 켜는 선택 사항이에요.

| 단계 | 켜지는 기능 | 필요한 것 | 소요 시간 |
|---|---|---|---|
| 0. 그냥 열기 | 일정·가계부·체크리스트·보관함 전부 (이 기기에만 저장) | 없음 | 0분 |
| 1. GitHub 배포 | 폰에서 접속 + 홈 화면에 앱으로 설치 | GitHub 계정 (무료) | 15분 |
| 2. Firebase 연결 | 온라인 저장 + 여러 기기 동기화 + **링크만으로 동행자 공유** | 구글 계정 (무료, 카드 불필요) | 15분 |
| 3. 구글맵 연결 | 앱 안 지도·경로 검색·장소 자동완성 | 구글 계정 + 결제 카드 등록 | 20분 |

> 3단계는 카드 등록이 필요하지만, 아래 안내대로 **사용량 상한을 걸면 요금이 나올 수 없는 구조**로 만들 수 있어요. 부담되면 3단계는 건너뛰세요 — 경로 버튼이 구글맵 앱으로 연결되는 방식으로 작동합니다.

---

## 0단계 — 일단 써보기

`index.html` 파일을 더블클릭해서 브라우저로 열면 바로 작동합니다.
"새 여행 만들기"로 시작하세요. (데이터는 이 컴퓨터/브라우저에만 저장됩니다)

---

## 1단계 — 인터넷에 올려서 폰에 설치하기 (GitHub Pages)

1. https://github.com 접속 → **Sign up**으로 무료 가입
2. 로그인 후 오른쪽 위 **+** → **New repository**
   - Repository name: `travel-planner`
   - **Public** 선택 → **Create repository**
3. 만들어진 페이지에서 **uploading an existing file** 링크 클릭
4. 이 폴더의 모든 파일·폴더(`index.html`, `css`, `js`, `icons`, `manifest.json`, `sw.js`)를
   창에 **드래그 앤 드롭** → 아래 **Commit changes** 버튼
   - 폴더째 드래그하면 폴더 구조가 유지됩니다
5. 저장소 상단 **Settings** 탭 → 왼쪽 메뉴 **Pages**
   - Branch: `main` 선택, 폴더 `/ (root)` → **Save**
6. 1~2분 후 같은 화면에 주소가 표시됩니다:
   `https://내아이디.github.io/travel-planner/`
7. **폰에 설치하기**
   - **아이폰**: Safari로 위 주소 접속 → 공유 버튼(□↑) → **홈 화면에 추가**
   - **안드로이드**: Chrome으로 접속 → 메뉴(⋮) → **홈 화면에 추가** (또는 "앱 설치")

> 이후 앱을 수정하면 GitHub 저장소에서 파일을 다시 업로드하면 됩니다 (같은 이름이면 덮어쓰기).

---

## 2단계 — 온라인 저장 켜기 (Firebase, 카드 불필요)

> **앱에는 로그인 화면이 없습니다.** 여행마다 아무도 못 맞히는 긴 코드가 부여되고,
> 그 코드가 담긴 **공유 링크를 아는 사람만** 해당 여행을 열 수 있는 방식이에요.
> 아래 설정은 회원님이 한 번만 하면 되고, 동행자는 아무것도 설정할 필요가 없습니다.

### 2-1. 프로젝트 만들기
1. https://console.firebase.google.com 접속 → 구글 계정 로그인
2. **프로젝트 만들기** → 이름 `travel-planner` → (애널리틱스는 꺼도 됨) → 만들기

### 2-2. 익명 인증 켜기 (사용자에게는 보이지 않는 자동 인증)
1. 왼쪽 메뉴 **빌드 → Authentication** → **시작하기**
2. 목록 아래쪽 **익명(Anonymous)** 선택 → **사용 설정** 토글 켜기 → 저장

> 이건 앱이 백그라운드에서 자동으로 처리합니다. 사용자는 로그인 화면을 보지 않아요.
> 이 설정 덕분에 외부에서 데이터베이스를 함부로 건드리지 못하게 막을 수 있습니다.

### 2-3. 데이터베이스 만들기
1. 왼쪽 메뉴 **빌드 → Firestore Database** → **데이터베이스 만들기**
2. 위치: `asia-northeast3 (서울)` → **프로덕션 모드**로 시작
3. 만들어진 후 상단 **규칙(Rules)** 탭 → 내용을 아래로 전부 교체 → **게시**

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /trips/{tripId} {
      // 여행 코드를 정확히 아는 경우에만 열람·수정 가능
      allow get, create, update, delete: if request.auth != null;
      // 목록 조회(전체 훑기)는 완전히 차단 — 남의 여행을 찾아낼 수 없음
      allow list: if false;
    }
  }
}
```

> `allow list: if false` 가 핵심입니다. 이게 있으면 누구도 "여행 목록 전체 보여줘"를
> 할 수 없고, 오직 링크에 담긴 정확한 코드로만 접근할 수 있습니다.

### 2-4. 앱에 연결하기
1. 왼쪽 위 **프로젝트 개요 옆 톱니바퀴 → 프로젝트 설정**
2. 아래로 내려 **내 앱** → **웹 앱(</>)** 아이콘 클릭 → 별명 입력 → 앱 등록
3. 화면에 나오는 `firebaseConfig = { ... }` 안의 내용을 복사
4. 이 폴더의 `js/config.js` 파일을 메모장으로 열고, `firebase: null` 부분을
   예시처럼 교체 (파일 안에 예시가 적혀 있어요)
5. 저장 후 GitHub에 `config.js`를 다시 업로드

### 2-5. 승인 도메인 추가
1. Firebase 콘솔 → **Authentication → 설정 → 승인된 도메인**
2. **도메인 추가** → `내아이디.github.io` 입력 → 추가

이제 앱을 열면 **로그인 없이 바로** 시작되고, 모든 데이터가 온라인에 저장됩니다.
홈 화면 오른쪽 위 **공유중 N명** 버튼 → **링크 복사**로 동행자에게 링크를 보내면,
동행자는 그 링크를 누르기만 해도 같은 여행을 보고 함께 편집할 수 있어요.

## 3단계 — 구글맵 켜기 (선택, 카드 등록 필요)

### 3-1. API 켜고 키 발급
1. https://console.cloud.google.com 접속 → 상단에서 Firebase로 만든 `travel-planner` 프로젝트 선택
   (2단계를 건너뛰었다면 새 프로젝트 생성)
2. 처음이면 **결제 계정 만들기** 안내에 따라 카드 등록
3. 왼쪽 메뉴 **API 및 서비스 → 라이브러리**에서 아래 3개를 각각 검색해 **사용(Enable)**:
   - **Maps JavaScript API**
   - **Directions API**
   - **Places API**
4. **API 및 서비스 → 사용자 인증 정보 → + 사용자 인증 정보 만들기 → API 키**
5. 만들어진 키를 복사해서 `js/config.js`의 `mapsApiKey: ""` 따옴표 안에 붙여넣기 → GitHub에 재업로드

### 3-2. 키 보호 (필수!)
`config.js`는 누구나 볼 수 있으므로 키를 꼭 잠가야 해요.
1. **사용자 인증 정보**에서 방금 만든 키 클릭
2. **애플리케이션 제한사항** → **웹사이트** 선택 → 항목 추가:
   - `https://내아이디.github.io/*`
3. **API 제한사항** → **키 제한** → 위 3개 API만 체크 → 저장

### 3-3. 요금 원천 차단 (필수!)
월 무료 한도(기능별 10,000회)를 넘지 못하게 일일 상한을 겁니다.
1. **API 및 서비스 → 사용 설정된 API** → **Maps JavaScript API** 클릭 → **할당량(Quotas)** 탭
2. "Map loads per day" 항목 연필 아이콘 → **300** 입력 → 저장
3. 같은 방법으로 **Directions API**의 "Requests per day" → **300**,
   **Places API**의 "Requests per day" → **300** 설정
4. (권장) 메뉴 **결제 → 예산 및 알림** → 예산 만들기 → 금액 1,000원 → 알림 저장

> 하루 300회 × 31일 = 최대 9,300회 < 무료 10,000회 → **요금이 청구될 수 없습니다.**
> 여행 중 한도가 부족하면 숫자를 조금 올려도 무료 범위 안이면 괜찮아요.

## 자주 묻는 것

**Q. 폰을 바꾸면 데이터가 사라지나요?**
2단계(Firebase)를 설정했다면, 여행의 **공유 링크만 저장해두면** 새 폰에서 그 링크를 열어
그대로 이어서 쓸 수 있습니다. 링크를 메모나 카톡 "나에게 보내기"로 남겨두세요.
설정 전이라면 앱의 설정 → **데이터 백업**으로 파일을 저장해두면 됩니다.

**Q. 링크가 유출되면 어떻게 되나요?**
링크를 아는 사람은 그 여행 하나만 볼 수 있습니다 (다른 여행은 볼 수 없어요).
걱정되면 새 여행을 만들어 내용을 옮기세요. 이전 링크는 그 즉시 다른 여행이 되므로
유출된 링크로는 새 여행에 접근할 수 없습니다.

**Q. 로그인이 없는데 안전한가요?**
여행 코드는 20자리 무작위 문자라 추측이 사실상 불가능하고, 서버 규칙에서
"목록 조회"를 완전히 차단해두어 남의 여행을 찾아낼 방법이 없습니다.
개인 여행 기록 수준에서는 충분한 보호입니다.

**Q. 오프라인에서도 되나요?**
일정·가계부·체크리스트·보관함은 오프라인에서도 열람/입력이 되고,
인터넷이 연결되면 자동으로 동기화됩니다. 지도·경로 검색만 온라인이 필요해요.

**Q. 동행자도 뭔가 설치해야 하나요?**
아니요. 같은 주소로 접속해서 구글 로그인 후, 초대 코드만 입력하면 됩니다.
