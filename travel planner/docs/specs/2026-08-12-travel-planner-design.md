# 해외여행 플래너 앱 — 설계 문서

작성일: 2026-08-12
상태: 기능 설계·디자인 시안 컨펌 완료 (2026-08-13) / 앱 1차 구현 완료
추가 확정: 홈 상단 도시 이미지, D-Day 시기별 자동 전환(전/중/후), 예산 제거 후
총 소비 표시, 홈·가계부 카테고리 도넛 그래프, 체크리스트 구성원별 담당·필터

## 1. 개요

모바일 중심의 해외여행 플래너 웹앱(PWA). 비전공자도 유지·관리 가능한 구조로 제작하고,
GitHub Pages 무료 호스팅으로 배포하여 스마트폰 홈 화면에 추가해 앱처럼 사용한다.

## 2. 확정 사항

| 항목 | 결정 |
|---|---|
| 앱 형태 | 호스팅형 웹앱(PWA), GitHub Pages 배포 |
| 지도 | Google Maps Platform 공식 내장 (지도 표시 + 경로 검색 + 장소 자동완성) |
| 데이터 저장 | Firebase 무료 플랜 (Google 로그인 + Firestore 클라우드 동기화) |
| 비용 | 무조건 무료 운영 — Google Cloud API 일일 쿼터 상한 설정으로 과금 원천 차단 |
| 디자인 | 토스(Toss) 앱 스타일 참고. 이모티콘 배제, 가독성 우선 |
| 제작 절차 | 설계 → 디자인 시안 컨펌 → 코드 설계 → 제작 |

## 3. 화면 구성 (하단 탭 5개)

1. **홈** — D-Day 카운트다운, 오늘 일정 요약, 예산 잔액, 체크리스트 진행률
2. **일정** — 날짜별 타임라인 ↔ 표 보기 전환. 연속된 일정 사이 이동 경로(대중교통/도보/차량)
   자동 조회 및 소요시간 표시, 탭하면 앱 내 지도에서 경로 상세 확인
3. **가계부** — 현지 통화 입력 → 원화 자동 환산(무료 환율 API), 카테고리별 기록,
   예산 대비 잔액, 일자별·카테고리별 지출 그래프
4. **체크리스트** — 기본 템플릿 제공 + 직접 추가, 완료 체크, 진행률 표시
5. **보관함** — 항공편·숙소 예약정보, 여권 정보, 긴급 연락처 등 메모 보관

여러 여행을 생성·관리 가능. 초대 코드로 동행자와 여행 공유(공동 편집).

## 4. 기술 구성

- 프론트엔드: HTML/CSS/JavaScript (빌드 도구 없이 단순 구조 유지)
- 호스팅: GitHub Pages (무료)
- 백엔드: Firebase Spark 플랜 — Auth(Google 로그인), Firestore(데이터), 오프라인 캐시 활성화
- 지도: Google Maps JavaScript API + Directions(대중교통 포함) + Places Autocomplete
  - 무료 한도: 기능별 월 10,000회 수준. **일일 쿼터 상한을 낮게 설정해 과금 자체가 불가능하게 구성**
- 환율: 키 불필요 무료 환율 API (오프라인 시 마지막 환율 사용)
- PWA: manifest + service worker (앱 아이콘, 오프라인 셸)

## 5. 오프라인 동작

일정·가계부·체크리스트·보관함은 오프라인에서 열람/입력 가능(재연결 시 자동 동기화).
지도·경로 검색·장소 자동완성만 온라인 필요.

## 6. 사용자 준비 사항 (단계별 안내 예정)

1. Google Cloud 가입 + 결제 수단 등록 + Maps API 키 발급 + 쿼터 상한/예산 알림 설정
2. Firebase 프로젝트 생성 (카드 불필요)
3. GitHub 계정 생성 (호스팅)
